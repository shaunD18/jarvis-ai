JARVIS iPhone Starter — Version 1

WHAT THIS IS
A free, installable Progressive Web App starter. It includes a local assistant interface, browser speech features where supported, on-device task/goal/paper-trade notes, a security checklist, and offline caching after first load.

IMPORTANT LIMITATIONS
- This is starter mode, not a full cloud AI assistant. It does not connect to an AI model yet.
- No system is unhackable. This app cannot scan or clean the whole iPhone, remove hackers, or control other apps.
- Paper trading only. It never places real trades or moves money.
- Data is stored in this browser's local storage. Clearing website data or using Clear app data deletes it. It is not synced or backed up automatically.

INSTALL ON IPHONE
1. Host this folder on an HTTPS website. GitHub Pages is one free option; you must create/sign into your own account and upload these files.
2. Open the published HTTPS site in Safari on your iPhone.
3. Tap Share -> Add to Home Screen -> Add.
4. JARVIS will appear as an icon and can open in its own app-like window.
5. Open it once while online so its files can be cached for offline use.

REMOVE / UNINSTALL
- Touch and hold the JARVIS icon on your Home Screen -> Remove App -> Delete Bookmark (wording may vary by iOS version).
- This removes the Home Screen app shortcut. To also erase its saved data, use Clear app data inside JARVIS, or clear Safari website data in iPhone Settings.
- You can reinstall it later by visiting the website and adding it to the Home Screen again.

PRIVACY
No analytics, trackers, ads, or external API calls are included in this starter. Your entries remain in local browser storage on this device unless you choose to clear them.
